Foyer uses Shopify’s **metafields** to add copy and information for donations, upsell recommendations, discounts and Gift Aid.

See Shopify's guide on [Metafields](https://help.shopify.com/en/manual/custom-data/metafields).


|  |  |  |
| --------------------------------- | ---------------- | --------------------------------------------------------------------------------- |
| **Variant metafield definitions** |  |  |
| Foyer - SOR Commission Percentage | Single line text | Sale-or-return commission %. Overrides the product value. |
| Foyer - Xero Tax Rate | Single line text | Exact Xero tax rate NAME. Overrides the product value. |
| Foyer - Xero Account Code | Single line text | Xero nominal. Overrides the product value. Foyer reads the leading 4 digits only. |
| Foyer - Membership Type | Single line text |  |
| Foyer - Product Type | Single line text |  |
| Foyer - Membership Card | True or false |  |
| Foyer - Ticket Description | Single line text |  |
| Foyer - Giftaidable | True or false |  |
